# Diabetes_CDSS_Ex

1. 주요 임상 지표(FPG, HbA1c)
기본 설정값 기준:

공복 혈당 (FPG): 95 mg/dL (기준: 100 mg/dL 미만)

당화혈색소 (HbA1c): 5.4% (기준: 5.7% 미만)

2. 위험 확률(2.7%)
연령(45세) 및 무가족력 기준:

혈당 관련 핵심 바이오마커(FPG, HbA1c)가 정상일 때, 45세 성인의 2형 당뇨병 발병 위험률이 2~3% 수준으로 산출되는 것을 예로써 보여준 것임

0%가 아닌 이유:

나이가 40대를 넘어섬에 따라 발생하는 연령 증가에 따른 기본 위험 지분(Baseline Risk)이 반영된 수치이므로, 0%가 아닌 2.7%로 계산되었다. 이는 로지스틱 모델의 특성이 반영된 것임

3. CDSS 사용 예
의료진의 임상적 판단에 따라서 현재 당뇨병이나 당뇨 전단계 소견 등 필요한 약물이나 정밀 검사 등을 권고하는 등 정기 검진 및 일반 건강 관리(식단/운동) 수준으로 가이드 라인을 제시할 수 있는 임상결정보조시스템으로써의 사용성을 보여주는 예시임
