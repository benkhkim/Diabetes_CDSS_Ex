현재 구현된 앱 코드에 적용된 예측 모델은 통계학 및 머신러닝 기반의 '로지스틱 회귀(Logistic Regression)' 구조를 활용한 비선형 위험 스코어링 모델입니다.

1. 수학적 모델 수식
입력된 임상 인자들을 선형 결합하여 위험 스코어(Score)를 산출한 후, 시그모이드 함수(Sigmoid Function)를 통과시켜 0~1 사이(0%~100%)의 발병 확률(Prob)로 변환합니다.

Score = -6.0 + (0.035 * Age) + (0.8 * FamilyHistory) + 0.05 * (FPG - 90) + 1.5 * (HbA1c - 5.0)

Prob = 1 / (1 + exp(-Score))

2. 가중치(파라미터)의 임상적 의미
절편 (Intercept = -6.0): 기저 위험도(Baseline Risk)를 낮게 설정하여, 모든 인자가 완벽한 정상일 때 발병 확률이 0%에 가깝도록 조정하는 역할입니다.

HbA1c 가중치 (1.5): 당화혈색소는 최근 2~3개월간의 평균 혈당을 반영하는 가장 강력한 지표이므로 가장 높은 가중치가 부여되어 있습니다. (HbA1c가 1%p 상승할 때마다 오즈비(Odds Ratio)가 급격히 증가)

FPG 가중치 (0.05): 공복 혈당의 단기 변동성을 반영합니다. Baseline인 90 mg/dL을 초과하는 수치만큼 위험 스코어를 높입니다.

가족력 가중치 (0.8): 직계 가족력이 있을 경우 유전적 요인으로 인한 위험도를 약 2.2배(e^0.8 약 2.22) 증가시킵니다.

나이 가중치 (0.035): 연령 증가에 따른 인슐린 저항성 증가 및 췌장 beta-세포 기능 저하를 완만하게 반영합니다.

3. Rule-based 진단 로직과의 하이브리드 결합
본 CDSS 프로토타입은 확률 모델(로지스틱 회귀)뿐만 아니라 미국당뇨병학회(ADA)의 임상 가이드라인(Rule-based)을 동시에 적용하는 구조입니다.

Rule 1: FPG 126 mg/dL 이상 또는 HbA1c 6.5% 이상 -> 당뇨병 유소견 (High Risk / Diabetic Range)

Rule 2: FPG 100~125 mg/dL 또는 HbA1c 5.7~6.4% -> 당뇨병 전단계 (Prediabetes)
